Explain My Metrics

3 refined finalists (top of page) + 8 supporting explorations. A meaningful share of Mailchimp's "data inaccuracy" VOC isn't bad data — it's metric-clarity confusion. Every mockup targets all 8 confusion modes — including how Mailchimp's numbers compare to other platforms (Shopify, Triple Whale, Klaviyo, GA4), where the data came from, and when it was last updated.

3 consolidated mockups

Three takes on the same idea: a compact tooltip with a consistent format that addresses all 7 confusion modes without overloading the user. All three show the same 3 things upfront (📖 Definition · ⏱ Freshness · 📍 Source), tuck the rest into two collapsed accordions (More details + Related articles), and offer an inline Analytics Agent follow-up. No right rail anywhere. F1 and F2 explain individual KPI tiles (different triggers); F3 brings the same pattern to charts.

F1
Persistent ⓘ icon → compact tooltip
Every metric label has a small ⓘ icon. Click it → tooltip with a consistent format every time: definition + "updated 4 min ago, auto-refreshes every 15 min" + "Source: Mailchimp + Shopify" upfront. Two accordions hold the rest: More details (date, benchmark, vs other metric, attribution, compare to platforms) and Related articles (KB). Agent follow-up at the bottom. No right rail anywhere.

Tier 1 · Static

Cheap wins — no AI required

Captures ~60% of VOC gains for ~10% of the build cost. Should ship first.

01
Inline tooltip with un-rounded value
Every metric label gets a ⓘ icon. Hover or click → small popover with one-sentence definition, the actual unrounded value, what's included/excluded, and a KB link. Pure static UX, deployable in days.
Tactic: Just-in-time disclosure
Solves
📖 Definition 📅 Date range 🎯 Benchmark ⚖️ vs other metric 🔍 Precision 🌐 Attribution 📍 Source ⏱ Freshness
→
02
Smart precision footnote
Auto-detect when display rounding hides nuance ("100% delivery rate" when it's actually 99.74%, "0% open rate" when it's 0.04%). Subtle * reveals the real value, and the popover surfaces the full definition, date range, benchmark, scope, and similar metrics. Catches the exact 3/27 VOC example automatically.
Tactic: Proactive transparency
Solves
📖 Definition 📅 Date range 🎯 Benchmark ⚖️ vs other metric 🔍 Precision 🌐 Attribution 📍 Source ⏱ Freshness
→
03
Calculation breakdown drawer
Click any KPI tile → slide-out drawer shows the math with the user's actual numbers: definition, formula with their values, precision footnote, date range, benchmark callout, what's included/excluded, and an "often confused with" section. Verify-with-CSV button at the bottom.
Tactic: Calculation transparency
Solves
📖 Definition 📅 Date range 🎯 Benchmark ⚖️ vs other metric 🔍 Precision 🌐 Attribution 📍 Source ⏱ Freshness

Tier 2 · AI · Contextual

AI explanations — pulled into the chart, on demand

The user's screenshot direction. AI agent embedded in the dashboard, with KB citations.

04
"Explain this metric" AI entry point
A per-tile AI explanation pattern. Hover any metric → small button: "Explain this metric." Click → AI opens a right rail with definition, the date range and what it covers, benchmark health check, similar-but-different metrics, precision notes, and attribution scope — all tailored to their current values. Pattern lives directly on the metric.
Tactic: Per-metric contextual explanation
Solves
📖 Definition 📅 Date range 🎯 Benchmark ⚖️ vs other metric 🔍 Precision 🌐 Attribution 📍 Source ⏱ Freshness

05
"Explain this chart" pill + right rail
The user's original sketch, refined. Pill on every chart and KPI tile. Click → right rail opens with AI explanation of that specific component, citing 1–3 KB articles inline as hyperlinks. Pre-baked follow-up chips ("Why doesn't this match GA?", "How is attribution calculated?"). Conversation persists as you click between charts.
Tactic: Conversational disclosure + KB grounding
Solves
📖 Definition 📅 Date range 🎯 Benchmark ⚖️ vs other metric 🔍 Precision 🌐 Attribution 📍 Source ⏱ Freshness

Persistent Learn rail / agent mode
A pinnable right-rail KB browser + conversational agent that lives alongside the dashboard (not behind a pill). Auto-surfaces articles relevant to the current page. Searchable across the full KB. Hyperlinks let users dig in without leaving. Aligned with the VOC quote: "Learn tab side-by-side with editing."
Tactic: Persistent knowledge access + window-in-window

Tier 3 · AI · Proactive & comparative

AI catches confusion before it becomes a VOC ticket

Most ambitious — the AI explains things the user hasn't asked about yet.

07
Anomaly auto-explain
When a metric spikes, drops, or hits a value users typically misread, an inline note appears under the number: definition snippet, the date range it covers, why it's anomalous (benchmark + precision), what the unusual cause is (attribution/list growth/etc), and a "don't confuse with" hint. Catches confusion before it becomes a ticket.
Tactic: Proactive disclosure + anomaly detection
Solves
📖 Definition 📅 Date range 🎯 Benchmark ⚖️ vs other metric 🔍 Precision 🌐 Attribution 📍 Source ⏱ Freshness
→
08
"Compare to" overlay — solve the GA mismatch
"Why doesn't this match Google Analytics?" is the #1 attribution VOC. Tackles it head-on: side-by-side scope breakdown, AI reconciliation math that closes the gap line-by-line, definition header explaining both metrics, benchmark for whether the gap size is normal, precision note on rounding, and a "don't confuse with" warning for similar-but-different metrics. Works for any cross-tool comparison.
Tactic: Reconciliation + scope visualization
